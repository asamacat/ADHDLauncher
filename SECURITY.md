# Security Policy

## Reporting a Vulnerability

If you discover a security or privacy issue in ADHD Launcher (such as unintended exposure of API keys or permissions), please report it privately via [GitHub Security Advisories](../../security/advisories/new) rather than opening a public issue.

## Privacy Guarantees
- ADHD Launcher does **not** collect telemetry, analytics, or personal usage logs.
- `PACKAGE_USAGE_STATS` is used strictly on-device to sort your app drawer by usage frequency.
- Optional AI API keys (BYOK) are stored locally on the device and are only transmitted directly to the user-configured API endpoint when explicitly triggered.
